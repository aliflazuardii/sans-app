# Sans Photo — Frontend

Frontend statis (HTML/CSS/JS murni) untuk GitHub Pages. Backend: Google Apps Script (REST API).

1. Isi `js/config.js` dengan URL Web App `/exec`.
2. Jalankan `git init` **di folder ini** lalu push ke repo GitHub dan aktifkan Pages (branch `main`, folder root).

Panduan lengkap: lihat `PANDUAN-INSTALASI.md`.
